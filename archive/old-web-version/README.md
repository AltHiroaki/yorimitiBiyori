# 旧Web版アーカイブ

このフォルダには、よりみち日和をWebアプリとして検討していた時期のファイルを保管しています。

現在の開発対象は、リポジトリ直下のFlutter版です。通常の実装では、このフォルダ内のファイルは触りません。

## 移動したもの

- `src/`
  - React / TypeScript版の実装メモや部品
- `docs/requirements.md`
  - Google Calendar連携を前提にした古いWebアプリ案
- `docs/coding-rules-guide.md`
  - React / TypeScript / Vite / Tailwind前提の説明
- `docs/file-separation-guide.md`
  - React版のディレクトリ構成を前提にした説明

## 現在の作業場所

- Flutterアプリ本体: `lib/`
