このファイルは、よりみち日和の MVP を完成させるための実装順序を整理するものです。

---

## 目的

最初から Google Calendar 連携や Firebase を入れるのではなく、まずは以下の中心機能を完成させます。

```text
条件を選ぶ → 行動を提案する → 実施またはスキップを記録する → 履歴を見る
```

## 実装時の注意

- MVP ではログイン機能を入れない
- MVP では外部 API を入れない
- まずは動くものを優先する
- 画面より先にデータ構造とロジックを安定させる
- 仕様変更があったら、このファイルも更新する
