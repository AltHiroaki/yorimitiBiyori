# 要件定義：よりみち日和 Flutter版

このファイルは、現在のFlutter版よりみち日和で満たす要件を整理するためのものです。

仕様の正本は企画書 ver6（2026年提出版 PDF）と `よりみち日和 UIプロトタイプ/` です。詳細な画面・データ仕様は [仕様書](./仕様書.md) と [仕様要約](./仕様要約.md) を参照してください。

旧Web版の要件は `archive/old-web-version/docs/requirements.md` に移動しました。

## 1. プロジェクト概要

よりみち日和は、ユーザーが選んだ興味カテゴリと、そのカテゴリ固有の詳細設定をもとに、空き時間でできる小さな「よりみち」を提案するAndroid向けアプリである。MVPではAndroidのみを対象とし、iOS対応はMVP完成後の発展版で導入する。

ユーザーが自分で検索して行動を決めるのではなく、アプリが提案を出す。**カテゴリを選び、続けて簡単な詳細設定で好みを絞り込む二段階方式**により、ライト層にとってちょうどよい具体性を持った提案を、内容（説明）つきで届ける（料理はレシピも添える）。

## 2. 想定ユーザー

- 音楽・料理・読書・映画などに「興味はあるが深掘りまではしない」ライト層の大学生・社会人
- 待ち時間・移動時間などの「すきま時間」を持て余しがちな人
- 気分転換したいが、何をするか考えるのが面倒な人
- 興味はあるが、自分から調べるほどの気力はない人

## 3. 解決したい課題

- **体験の固定化**：好きでもいつも同じものを選んでしまう。固定化した行動パターンから抜け出すきっかけがない
- **「新しいもの」への踏み出しコスト**：違うものも試したいが、何を選べばよいかわからない。調べて選ぶ工程が面倒で結局同じになる
- **詳細情報がないと試せない**：「ボサノバを」「タジンを」と言われても、どんなものかわからないと試す気になれない

よりみち日和は、好きなカテゴリの中から「いつもとは違うもの」を詳細情報つきで提示することで、迷う時間を減らし、小さな行動を始めやすくする。

## 4. MVPの提供価値

- 興味カテゴリと、カテゴリ別の詳細設定（MVP は各カテゴリ「ジャンル」1 種類。複数項目は発展）をもとに提案を受け取れる
- 提案には内容（説明）が添えられ、料理はレシピを展開して確認できるため、知らないものでも試せる
- 実施やスキップを記録し、フィードバック付きであとから振り返れる
- 通知をきっかけに使えるため、アプリを自分から探しに行かなくてよい
- ログインなしで端末内に保存できる

## 5. 機能要件

### 5.1 オンボーディング

初回起動時に、ようこそ画面 → 興味カテゴリ選択 → 通知許可画面の3ステップを全画面で表示する。全画面に現在位置（ステップ 1 / 3〜3 / 3）を表示し、2ステップ目以降は選択を保ったまま前へ戻れる。

ウェルカム画面では「好きなカテゴリを選ぶ → 初期設定では17:00〜21:00の間に1日1件だけ提案が届く → やってみたら履歴に残り、気分でなければ次へ送って後から戻せる」というアプリの1周を案内する。カテゴリ選択では選択数が提案の幅に影響することを伝え、通知許可では頻度と初期時間帯、後から変更できることを伝える。オンボーディングでは詳細設定を尋ねず、ジャンルなどは提案を見てから提案設定で絞り込めることを予告する。レシピ展開など個別機能の操作説明はオンボーディングへ入れない。

通知許可を「あとで」にしても、手動提案だけで利用できる。

### 5.2 興味カテゴリ登録

ユーザーはオンボーディングまたは設定画面で、興味のあるカテゴリを複数選択できる。

MVP のコアカテゴリは、音楽・料理・読書・映画の4種とする（企画書 ver6 準拠）。散歩・運動・芸術などは発展で追加する（散歩は定義・提案データを先行整備済み）。

### 5.3 提案条件の設定（二段階方式）

ユーザーは提案設定画面で、以下の二段階で条件を設定・保存できる。

1. **第1段階：カテゴリ選択**（複数選択）
2. **第2段階：選択した各カテゴリの詳細設定**（カテゴリ固有。各グループは未選択＝指定なし＝絞り込まない）

二段階の後に、カテゴリ横断の任意条件として「時間の上限」を単一選択できる。選択肢は `指定なし / 〜15分 / 〜30分 / 〜60分`、初期値は `指定なし` とする。これは旧仕様の必須だった共通の「使える時間」ではなく、カテゴリ・詳細設定で作った候補集合に対する安全上限として扱う。

MVP の詳細設定（各カテゴリ「ジャンル」1 種類。映画は「気分」。企画書 ver6 表3 準拠）：

- 音楽：ジャンル（ポップス/ジャズ/クラシック/洋楽）
- 料理：味覚・ジャンル（和食/洋食/中華/イタリアン/アジア風/激辛/さっぱり/ガッツリ）
- 読書：ジャンル（エッセイ/小説/ノンフィクション/詩集）
- 映画：気分（泣ける/笑える/考えさせる）
- 散歩（発展）：目的（気分転換/運動/発見）

発展で追加する詳細設定（企画書 ver6 表3 の「発展版で追加」）：音楽＝言語・気分、料理＝栄養素・ダイエット、読書＝読書時間・入手予算、映画＝上映時間・視聴先。

**難易度・移動距離・必須の共通の使える時間は設けない**（旧仕様から廃止）。時間の上限は任意であり、通知アクションからは変更しない。

### 5.4 提案表示

アプリは、カテゴリ＋詳細設定に合う提案を1件表示する。

提案カードには、タイトル、説明文、タグを表示する。所要時間はタグではなく参考情報として、タグと分けた補助色の「目安 約N分」で表示する。時間上限が指定されている場合は、`estimated_minutes` が上限以内の提案だけを候補とする。料理の提案では「詳しく見る」からレシピを展開・収納できる。提案画面の上部には、選択中カテゴリと有効な詳細設定を示す提案条件カードを表示し、時間上限は指定時だけ「時間の上限：〜N分」と表示する。詳細設定が未選択の場合は「詳細設定：すべてのジャンルから」と表示する。

### 5.5 再提案

ユーザーは「スキップして次の提案」で同じ条件のまま別の候補を表示できる。このとき表示中だった提案はスキップとして記録する。

### 5.6 実施記録とフィードバック

「やってみる」を押すと完了モーダルが表示され、「よかった / 普通 / 合わなかった」の3択でフィードバックを選び、実施済みとして履歴に保存できる。

### 5.7 履歴表示

ユーザーは過去に実施またはスキップした提案を一覧で確認できる。期間は「今週 / 全期間」、ステータスは「すべて / 実施 / スキップ」で切り替えられる。初期状態は「今週 / すべて」とする。

「今週」は端末ローカル時刻の月曜日00:00から現在までとする。履歴画面には、選択期間の実施数、スキップ数、合計時間（分）を表示する。合計時間は期間内の実施レコードの `estimated_minutes` の合計とし、ステータスの絞り込みではサマリーを変えない。

保存済み履歴が0件のときは空状態と提案画面への導線を表示する。履歴はあるが絞り込み結果が0件のときは、「今週の履歴はありません」または「この条件の履歴はありません」と条件変更の導線を表示する。絞り込み状態は端末へ保存しない。

### 5.8 履歴削除

設定画面から端末内の履歴を削除できる。削除前に確認を表示し、取り消せないことを明示する。

### 5.9 通知

ユーザーは通知時間帯（開始・終了、デフォルト 17:00〜21:00）と通知の ON/OFF を設定できる。開始 == 終了は固定時刻として扱う。

設定した時間帯の範囲内で、毎日 1 回ランダムな時刻にローカル通知を表示する。**通知文言は時間（分数）を名指ししない柔らかい誘い**（例「暇な時間って存在しますか？」）とし、通知本文のタップで提案画面を開く（保存済みのカテゴリ＋詳細設定＋時間上限で提案する）。**時間を選ぶ通知アクション（15/30/60分）は設けない**。

発展版では、固定時刻だけでなく通知時間帯を設定し、その範囲内で毎日ランダムな時刻に通知する方式を検討する。MVPでは固定時刻通知を優先する。

## 6. 非機能要件

- スマートフォンで読みやすく、押しやすいUIにする（Material 3、グリーン基調）
- カテゴリと詳細設定はマスター定義から駆動し、カテゴリ・詳細設定の追加を後から行えるようにする
- 提案表示までの待ち時間を短くする
- 端末内保存の読み書きに失敗しても画面が壊れないようにする
- MVPでは通知の挙動をAndroid EmulatorとAndroid実機で確認する
- MVPではログインや外部APIを使わず、個人情報の扱いを最小限にする

## 7. MVPでやらないこと

- ユーザーログイン・Googleアカウント連携（設定画面に「未連携」の行として表示するのは可）
- Google Calendar連携
- Firebase連携
- Google MapsやPlaces APIの利用
- 位置情報を使った提案
- YouTube APIや音楽サービス連携
- AI API（Claude API）によるリアルタイム生成
- 通知時間帯のランダム化、時間を選ぶ通知アクション
- クラウド保存やアカウント同期
- iOS版の生成、ビルド、通知確認

これらはMVP完成後の発展機能として扱う。

## 8. 成功条件

- 初回起動時にオンボーディングで興味カテゴリを登録できる
- 提案設定でカテゴリを選び、カテゴリ別の詳細設定と任意の時間上限で好みを絞り込める
- 条件に合う提案が1件（説明つき、料理はレシピつきで）表示され、「スキップして次の提案」で再抽選できる
- 「やってみる」からフィードバック付きで実施記録を保存できる
- 履歴画面で今週 / 全期間とステータスを切り替え、期間連動の実施数・スキップ数・合計時間と記録一覧を確認できる
- 通知から提案画面を開ける
- 設定画面から履歴を削除できる
