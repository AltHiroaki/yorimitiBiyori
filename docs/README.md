# docs ディレクトリ構成

ドキュメントが増えてきたため、用途ごとにフォルダを分離する。

## 推奨構成

```
docs/
├─ README.md
├─ github/
│  ├─ github-projects-guide.md
│  ├─ git-workflow.md
│  └─ pull-request-guide.md
├─ ai/
│  ├─ codex-guide.md
│  ├─ claude-guide.md
│  └─ prompts.md
├─ project/
│  ├─ requirements.md
│  ├─ specification.md
│  ├─ architecture.md
│  └─ meeting-notes.md
└─ presentation/
   ├─ script.md
   └─ presentation-plan.md
```

## github

GitHub運用ルールや開発フローを管理する。

## ai

Codex、Claude、ChatGPTなどAI利用に関する知見を管理する。

## project

よりみち日和そのものの仕様・設計・議事録を管理する。

## presentation

発表資料や台本に関する資料を管理する。
