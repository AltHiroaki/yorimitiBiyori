# GitHub Education 申請手順

更新日: 2026-05-29

この手順書は、和歌山大学の学生証を証明書類として使い、GitHub Education / GitHub Student Developer Pack に応募するためのメモです。

---

## 1. 申請前に準備するもの

### 必要なもの

- GitHub の個人アカウント
- 和歌山大学の学生証
- 可能であれば、和歌山大学の大学メールアドレス
- 学生証の情報が読める鮮明な写真

### 学生証で確認されやすい情報

| 項目 | 確認内容 |
|---|---|
| 氏名 | GitHub アカウントの名前と大きく矛盾しないこと |
| 学校名 | 和歌山大学 / Wakayama University が確認できること |
| 在学中と分かる情報 | 有効期限、入学年度、在籍期間などが分かること |
| 学生番号 | 基本的には見えていて問題ないが、不安な場合は隠しすぎない範囲で対応する |

GitHub Education では、現在学生であることを確認できる書類が求められる。学生証に有効期限や在籍期間が載っていない場合は、在学証明書、時間割、成績証明書などを追加で用意しておく。

---

## 2. GitHub アカウントを確認する

1. GitHub にログインする。
2. プロフィール名が学生証の氏名と大きく食い違っていないか確認する。
3. 可能であれば、大学メールアドレスを GitHub アカウントに追加して認証する。

大学メールアドレスの追加は必須ではない場合もあるが、学校との関連付けを補強できる。

---

## 3. 申請ページを開く

以下のどちらかから申請を開始する。

- GitHub Education の学生向けページ  
  https://github.com/education/students
- GitHub Docs の学生申請手順  
  https://docs.github.com/en/education/about-github-education/github-education-for-students/apply-to-github-education-as-a-student

GitHub にログインした状態で、`Get verified`、`Join GitHub Education`、または `Start an application` に進む。

---

## 4. 申請区分を選ぶ

申請区分では、学生として申請する。

学校名は、候補に合わせて以下のどちらかで入力する。

```text
Wakayama University
```

または

```text
和歌山大学
```

英語表記の候補が出る場合は、`Wakayama University` を選ぶのが無難。

---

## 5. 学生証を撮影する

### 撮影条件

- 明るい場所で撮る。
- ピンぼけ、影、反射を避ける。
- 学生証全体をフレーム内に入れる。
- 氏名、学校名、有効期限または在籍期間が読めるようにする。
- 加工しすぎない。
- スクリーンショットではなく、実物の学生証を撮影する。

### 注意点

学生証に現在在学中だと分かる日付が写っているか確認する。日付がない、または現在の在籍が分かりにくい場合は、次のどれかを追加で使う。

- 在学証明書
- 時間割
- 成績証明書
- 学務システムの在籍情報画面

追加書類を出す場合は、氏名、学校名、現在の年度または在学期間が分かるものを選ぶ。

---

## 6. フォームを送信する

1. 学校名、学生区分、必要事項を入力する。
2. 学生証の写真をアップロードする。
3. 入力内容を確認する。
4. `Submit application` を押して送信する。

審査が通ると、GitHub Education の特典を利用できるようになる。

---

## 7. 落ちた場合の対応

申請が通らなかった場合は、理由を確認して再申請する。

| 落ちやすい原因 | 対応 |
|---|---|
| 学生証の文字が読めない | 明るい場所で撮り直す |
| 現在在学中だと分からない | 在学証明書や時間割を追加する |
| 学校名が確認できない | 学校名がはっきり写るように撮る |
| 氏名が一致しない | GitHub プロフィール名を実名寄りにする |
| 書類の日付が古い | 現在の年度が分かる書類を使う |

GitHub 公式のトラブルシューティングでは、学生 status が明確でない場合や書類が不鮮明な場合、追加書類を求められることがある。

---

## 8. 和歌山大学の学生証で出すときのおすすめ構成

まずは以下で申請する。

```text
学校名: Wakayama University
証明書類: 和歌山大学の学生証
写真条件: 氏名、学校名、有効期限または在籍期間が読める鮮明な写真
```

学生証に有効期限や在籍期間が載っていない場合は、最初から以下の組み合わせにする。

```text
証明書類: 学生証 + 在学証明書 または 時間割
確認できる情報: 氏名、学校名、現在の年度、在学中であること
```
