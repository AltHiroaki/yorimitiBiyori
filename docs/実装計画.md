# 実装計画

このファイルは、Flutter 版 `よりみち日和` の MVP を完成させるための実装順序を整理するものです。

---

## 目的

最初から AI API、YouTube 連携、Google Calendar 連携、Firebase を入れるのではなく、まずは以下の中心機能を完成させます。

```text
興味を登録する → 通知で空き時間を選ぶ → 提案する → 実施またはスキップを記録する → 履歴を見る
```

MVP の中心体験は以下です。

```text
通知 → 15分 / 30分 / 60分 → 即提案
```

AI、バックエンド、クラウドデータベースは MVP 完成後の発展 Phase として扱います。

- [AI・バックエンド・データベース導入ガイド](./AI・バックエンド・データベース導入ガイド.md)

---

## 検証環境に関する前提

チーム内に macOS 環境がないため、MVP では Android のみを実装・検証対象とします。

- Android は Windows PC + Android Emulator / Android 実機で確認する
- iOS は MVP には含めない
- iOS 導入は、MVP 完成後の発展 Phase として扱う

詳細は以下を参照します。

- [iOS 導入方針と確認環境に関する懸念](./iOS導入方針と確認環境の懸念.md)

## 実装時の注意

- MVP ではログイン機能を入れない
- MVP では外部 API を入れない
- MVP では AI API を必須にしない
- まずは動くものを優先する
- 通知より先に、アプリ内で提案が動く状態を作る
- MVP は Android のみを対象にする
- iOS 導入は MVP 完成後の発展 Phase として扱う
- AI API キーを Flutter アプリに直接入れない
- AI バックエンドは MVP 完成後の発展機能として扱う
- 仕様変更があったら、このファイルも更新する
