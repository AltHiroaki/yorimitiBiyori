## Codex / AI agent に作業を依頼するときの渡し方

リポジトリのルールとして、AI agent は `CLAUDE.md` → `docs/rules/AGENTS.md` / `docs/rules/SKILL.md` を読む構成になっています。個別タスクを依頼するときは、以下を伝えると精度が上がります。

1. **読むべきファイル**：`docs/spec/仕様書.md`（該当セクション番号も指定。例：提案ロジックなら 6 章）＋ `docs/planning/実装計画.md` の該当タスク番号（例：1-2）
2. **完了条件**：実装計画に書いてある「完了条件」をそのまま貼る
3. **やらないこと**：仕様書 2.2「MVP で実装しない機能」に触れないこと、UI プロトタイプの React コードを移植しないこと
4. **終わったら**：`flutter analyze` と `flutter test` を実行して結果を報告させる

例（1-2 を依頼する場合）：

> docs/spec/仕様書.md の 6 章と docs/planning/実装計画.md の 1-2 に従って、提案ロジックを `lib/src/features/recommendation/suggestion_picker.dart` に純粋関数で実装してください。仕様書 10.1 の単体テストも書いてください。完了条件：時間・予算・距離・カテゴリ・直近除外・重みのテストがすべて通ること。
